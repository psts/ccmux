      What it owns

      Every session in this window is told what each repo owns, so work in this repo is handed to its session. Haiku writes it from the repo's CLAUDE.md and README; type your own line to override it.

      Hostnames

      Dev hostnames served over the tailnet. Each name routes to the port its app binds on its own — ccmux never tells the server where to listen.
